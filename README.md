# Daily Task Manager

A responsive To-Do List app built with HTML, CSS, and vanilla JavaScript.

## Features

- Add tasks with high, medium, or low priority
- Mark tasks complete or active
- Filter tasks by All, Active, and Completed
- Delete individual tasks or clear completed tasks
- Task summary for total, completed, and remaining items
- **Live date and time** shown in the page header, updated every second
- Task creation date and time shown in the task details
- Saves tasks in browser `localStorage`
- Responsive layout for desktop and mobile

## Files

```text
daily-task-manager/
├── index.html
├── style.css
├── script.js
└── README.md
```

## Run locally

1. Download and extract the ZIP.
2. Open `index.html` in your browser.

The date and time use your device's local time zone. For GitHub Pages, upload all four files to the root of your `daily-task-manager` repository and commit the changes.

## Technologies

HTML5, CSS3, JavaScript, and browser Local Storage.

## Note

Tasks are saved only in the browser where they were created. Clearing browser site data can remove them.
